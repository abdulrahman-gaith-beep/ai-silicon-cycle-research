# 呈现规范：编辑级数据表达

> 配合 SKILL.md 第 7 步使用。目标：让读者“hover 见事实、click 见记录”，每张图都能回溯到台账行。

## 目录
1. 版式骨架
2. 统计锚点（stat plaques）
3. 图表视觉语法
4. 标志性图型清单
5. 文体规范

## 1. 版式骨架

- 单页长卷（single-scroll），章节编号采用 `§n · 窗口名 · 年份区间` 形式。
- 开篇 = 执行摘要 + 一行式论点（“Is this time different?”式问句）+ 四个统计锚点。
- 全文一张“墙图”（wall chart）总览全部年份：阴影区=分析窗口，事件牌匾（event plaques）=关键事实，hover 出事实、click 出记录。
- 深潜（deep dive）章节独立编号（§9b/9c/9d…），每节只做一个应力测试。
- 结论 = 一张类比矩阵总表 + 情景算术 + 触发器卡片墙，不给单点 verdict。

## 2. 统计锚点

首页固定 3–4 个大数字锚点，格式：**数值**（粗体大字）+ 一句度量说明 + 台账编号。示例：

- **17.6×** — NVIDIA 数据中心收入，Q1FY24→Q1FY27 · K10
- **≈−39%** — FPGA 双寡头 2001 年回撤 · K17
- **0.80→≈1.21** — 资本开支/经营现金流，2025→2026E（est.）· K29

规则：数值必须来自台账；估计值带 ≈ 与 est. 标记；复合指标给区间。

## 3. 图表视觉语法

统一四种数据状态的画法，全报告一致：

| 数据状态 | 画法 |
|---|---|
| 实际值（actual） | 实心填充 |
| 估计值（estimate） | 空心描边 |
| 预测（forecast） | 斜纹/阴影填充 |
| 指引（guidance） | 虚线边框 |

- 每图编号 `FIG. n · 全大写短标题`，图下一句“看什么”说明 + 一行来源（指向台账行或外部记录）。
- 对数坐标用于跨数量级比较，且必须标注“精度基准不同——比较形状而非高度”（适用于 TOPS/TFLOPS 跨代对比）。
- 等距/象征性图型（如一片=10kwpm 的 CoWoS 板坯、堆叠层数=HBM 堆高的 die stack）优先于抽象坐标系——让物理直觉直接可见。
- 每个可交互元素（图块、时间线节点、矩阵格、触发器卡片）背后挂一条 adjudication 或台账记录。

## 4. 标志性图型清单

| 图型 | 用途 |
|---|---|
| 墙图（1985–2026 单线图） | 全时段总览 + 窗口阴影 + 事件牌匾 |
| 波形循环图 | 需求点火→产能假设失效→恐慌双订→块状到货→出清 的循环机制 |
| 公司生命线（lifelines） | 队列成员从创立到退出/存续的水平条 |
| 清算流带（sankey 式 ribbon） | 挑战者 → 去向，带宽≈交易金额 |
| 潜艇图（水位线） | 部署在水线下、披露在水线上，滞后 1–4 年 |
| 闸门评分块 | 每闸门 6 个评分块（供给基数/交期/资本密度/良率学习/定价权/绕行成本） |
| 判定矩阵（窗口×维度） | 蓝=same、斜纹=partial、灰=none |
| 裁决树（verdict tree） | 情景分支，不可定价分支画虚线 |
| 情景链图 | 支出路径 × 份额 → 收入倍数，标“分母相容” |
| 触发器卡片墙 | 每卡=证伪条件+当前读数+下一观察窗；状态三档：confirmed / partial / missing |

## 5. 文体规范

- 编辑文体（NYT/WSJ 特稿节奏）：段落即论点，每段一个加粗题眼句；克制使用最高级，数字自己说话。
- 关键术语首次出现时给操作定义（如“台阶”=10kwpm 产能增量）。
- 禁用空转连接词；过渡靠“上一段的未决问题”。
- 每个强主张附近必须有它的反方：「诚实的反论证是……」句式。
- 图表标题写结论而非内容（“Four gates, rigidity-ranked”优于“CoWoS capacity chart”）。
- 中英术语并置时保持一词到底（如全程用“出清”或全程用“clearing”，不混用）。
