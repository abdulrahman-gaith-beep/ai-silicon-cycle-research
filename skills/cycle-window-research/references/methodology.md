## 1. 窗口切分法

- 以**结构性事件**（技术范式转移、需求冲击、政策突变）为窗口边界，不按自然年代等分。示例：1985–95 FPGA 创立 / 1995–2003 光通信兴衰 / 2004–12 安静十年 / 2013–18 点火 / 2019–22 短缺与并购超级周期 / 2023–26 当前周期。
- 每个窗口开篇回答三个问题：这个窗口的**需求**是什么、**约束**在哪里、**清算**如何发生。
- 每个窗口收尾写“当时可知 / 当时不可知”两栏——这是防止后见之明污染的硬约束。
- 允许插入“间奏”（interlude）章节承载平行案例（如加密货币挖矿周期作为 AI 周期的镜子），但必须同时写明**镜像的边界**：哪些教训可迁移（振幅），哪些不可（持续性）。

## 2. 事实台账（K-register）规范

每个事实一行：`K{n} | 陈述 | 数值与单位 | 来源 | 数据时点 | 口径/财政年标注 | 估计标记`。规则：

- 编制性数字（compiled estimate）必须注明编制方法与分母（如“Top-4 capex，日历年口径，微软已日历化”）。
- 无公开共识的衍生值（如聚合 OCF）标 “working estimate”，并写明“不存在公共共识聚合值”。
- 财政年与日历年混用时，派生指标（如同比降幅）必须标注“窗口对齐的派生值”。
- 正文引用格式：`（事实陈述）· K17`，图表来源行指向台账区间（如 `K13–K16`）。

## 3. 重复模式词典

| 模式 | 定义 | 分析用途 |
|---|---|---|
| 清算文法（clearing grammar） | 每轮周期的出清方式：减记、并购、重组——而非破产清算 | 预测下行周期的退出形态与定价 |
| 潜艇模式（deploy first, disclose later） | 生产真相领先公开披露 1–4 年 | 对一切“新公告”按滞后折价解读；把未披露项挂为长期缺口 |
| 订单文法（NCNR） | 不可取消不可退货订单把不确定需求变成确定积压再变成确定库存 | 识别短缺的自我毁灭机制 |
| 双订单（double-ordering） | 链条每层只能看到自己的积压，超额订购结构性不可见 | 判断供应链数据的可信边界 |
| 闸门迁移（constraint migration） | 约束沿 晶圆→封装→内存→电网 移动，利润池随之移动 | 定位“收费站”资产 |
| 工具链选择变量 | 定制硅片作为编译器目标被购买；软件生态决定幸存者 | 评估挑战者时先看工具链深度，不看 TOPS |
| 阶梯三口径 | 出货量 → 产能分配 → 美元价值，从物理到金融的阶梯 | 渗透率主张必须说明站在哪一级 |

## 4. 类比矩阵构建

- 维度建议五选：需求现实性、约束位置、订单文法、清算机制、软件锁定。维度集一旦定义，全报告不得增减。
- 打分三档：same（实心）/ partial（斜纹）/ none（灰）。每格可点开 adjudication 备注。
- 矩阵的论点结构：若当前周期在 N-1 个维度上与某历史窗口 same，则**唯一 different 的那一格就是报告的核心命题**（例：约束位置不同 → 出清更慢、受益者不同、预警指标换组）。
- 类比必须附带“失效条件”：写明什么证据会杀死这个类比（如“capex 指引下修发生在利用率仍上行时——与 2001 年相反的顺序”）。类比是宽松的先验，不是模板。

## 5. 情景算术与 kill switch

- 基准情景 = 两步乘法：支出倍数 × 份额倍数。例：$500B/$330B ≈ 1.52×；20%/12% ≈ 1.67×；乘积 ≈ 2.5×。
- 敏感性表：行=支出倍数，列=份额倍数，3×3 网格，基准格高亮。
- kill switch 的设定标准：阈值不是任意数，而是“低于该值时情景的支出路径在算术上不可达”的增长率。情景死于自身输入失效的那一刻，而非持有者失去信念的那一刻。
- 附一条“虚线分支”承载不可定价风险（如政策分隔）：画出但不赋概率——假装能定价才是唯一不可证伪的作弊。

## 6. 幸存者/清算分析

- 先声明队列规则（cohort rule）：哪类公司、哪个成立年份区间、含哪些参照系成员，观察截止到何日。
- 终局分类要抗 one-liner：被收购 / 资产出售 / 授权交易 / 上市 / 独立存续 / 破产重组——并列展示，拒绝“全部死了”的简化。
- 读路径而非读总数：退出价格的方向（同一资产类别跨周期的相对定价）比退出数量更有信息量。
- 结论模板：「清算不是失败的委婉语——它是输掉的工具链被折叠进赢家组合的方式。」
